# SHIELD UI demo

## ▶ [SHIELD 데모 실행](https://hyunsik0213.github.io/SHIELD_DEMO/)

브라우저에서 사용 흐름을 체험할 수 있습니다. GitHub Pages 배포 완료 후 위 링크가 열립니다.

가상회의와 딥페이크 탐지 결과의 사용 흐름을 보여주는 정적 데모입니다.

## 실행

이 폴더의 `index.html`을 정적 웹 서버에서 제공합니다. GitHub Pages에 게시할 때도 이 파일을 진입점으로 사용합니다. 카메라·마이크·화면 공유·녹화는 브라우저 지원과 HTTPS 또는 localhost 환경이 필요합니다. 화면만 살펴볼 때는 HTML 파일을 직접 열 수도 있습니다.

환경 변수, API 키, 서버 연결, 별도 빌드 또는 패키지 설치가 필요하지 않습니다. 현재 시연 파일은 HTML/CSS/JavaScript이며 React/FastAPI/LiveKit 기반 실제 서비스는 별도 구현 계획입니다.

## 시연 흐름

1. 데모 계정으로 시작하거나 예시 이메일·아이디·닉네임으로 가입합니다.
2. 회의를 생성하고 이메일 또는 사용자 아이디로 초대합니다.
3. 초대 링크를 데모의 ‘회의 참여’ 입력란에 붙여 넣습니다. `shield.example`은 외부 서비스가 아닌 데모용 주소입니다.
4. 승인 대기, 통화·채팅 화면, 탐지 상태 시나리오를 체험합니다.
5. 녹화하려면 호스트로 회의 탭을 선택합니다. 채팅 영역과 예시 위험도를 합성합니다.
6. 나가기 또는 전체 종료 후 본인의 참여 구간 보안 결과를 확인합니다. 재입장은 별도 결과를 만듭니다.
7. 보안 결과를 삭제해도 녹화 보관함의 파일은 유지됩니다. 녹화 파일 삭제 시에도 보안 결과는 유지됩니다.

보안 결과는 열람·삭제만 제공하며 내보내기는 제공하지 않습니다. 녹화 파일은 호스트 계정의 보관함에서 재생·다운로드·삭제합니다.

## 데모의 범위와 데이터

- 원격 참가자와 위험도 점수는 예시 데이터입니다. 실제 다자간 통화, 서버 인증, ML 분석, 서버 녹화는 연결하지 않았습니다.
- 승인 대기의 ‘데모 상태 체험’ 버튼은 실제 호스트의 승인을 대신합니다.
- 화면에 설정된 참가자 이름과 계정은 시연용 예시입니다. 실제 개인정보나 재사용하는 비밀번호를 입력하지 마세요. 비밀번호는 저장·검증하지 않습니다.
- 계정·초대·결과는 localStorage, 녹화는 IndexedDB에 해당 브라우저 로컬로 저장됩니다. 다른 기기에는 동기화되지 않습니다.
- 녹화 화면·채팅에는 직접 입력하거나 공유한 내용이 포함될 수 있습니다. 실데이터 대신 예시 화면으로 시연하세요.
- 이 데모는 외부 API·분석 추적·CDN을 호출하지 않습니다. 웹 호스팅 제공자의 접속 로그와 브라우저 자체 동작은 별개입니다.
- 카메라·마이크·화면 캡처는 사용자의 조작과 브라우저 권한으로 시작합니다. 브라우저별로 오디오 캡처 범위가 다를 수 있습니다.
- 다른 사람과 같은 브라우저를 공유한다면 시연 후 해당 사이트의 저장 데이터를 지우세요. 실제 서비스용 계정 보안 기능은 아닙니다.

## 업로드 범위

이 폴더의 파일만 새 저장소에 올립니다. 상위 폴더의 기획서, 작업 파일, 브라우저 데이터, 녹화본과 개인 설정은 포함하지 않습니다. `.gitignore`는 이미 추적 중인 파일이나 과거 커밋의 비밀값을 제거하지 않습니다. 기존 저장소에 합칠 경우 기존 파일과 이력은 별도 점검 대상입니다.
